SHOPGRAPH — LOCAL AI PRODUCT / PRICE INTERPRETER
=================================================

PURPOSE
-------
Improve the path between raw_ocr JSON and the Data Base Builder review screen.

The existing filename/manual metadata logic remains authoritative for:
- Store
- Store Number
- Receipt Date

The new intelligence layer focuses only on:
- Is this line actually a purchased product?
- Product name
- Final item price

WHY
---
A raw line can contain several monetary values, for example:

    Chobani Fab 0% Blck Chry F 1 @ 10 for $10.00 1.00 You saved: $0.62

A simple decimal parser cannot know which amount is the final item charge.
The new layer sends the full ordered receipt text to the same local Ollama model
already installed for ShopGraph. It can use receipt context and distinguish:

    Product: Chobani Fab 0% Blck Chry
    Price:   1.00

from:
    promotion/reference amount: 10.00
    savings amount:             0.62

ARCHITECTURE
------------
New:
    utils/DataBaseBuilder/local_ai_receipt_interpreter.py

Changed:
    capabilities/OllamaReceiptAcquisitionPipeline/ollama_client.py
    utils/DataBaseBuilder/data_base_builder_main.py

The receipt is interpreted in ONE batch request rather than one Ollama call per
reviewed line.

SAFETY / FALLBACK
-----------------
- Local Ollama only. No cloud API is introduced.
- If Ollama is unavailable or returns invalid output, Data Base Builder prints a
  warning and falls back to the existing store-specific parser guesses.
- Store, Store Number, and Date are never taken from this AI interpretation.
- Common Name and Sub-Category are not generated by this layer.
- The normal interactive review screen remains the final authority.
- Existing skip-term behavior remains unchanged.
- The retired receipt_item_interpreter.py is not restored or reactivated.

EXPECTED EXAMPLE
----------------
Raw:
    Chobani Fab 0% Blck Chry F 1 @ 10 for $10.00 1.00 You saved: $0.62

Proposed interpretation should normally become approximately:
    Product: "Chobani Fab 0% Blck Chry"
    Price 1: "1.00"

while the existing code continues to supply:
    Store: "Publix"
    Store Number: "120"
    Date 1: "09/07/2026"
