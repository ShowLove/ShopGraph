ShopGraph - OCR Acquisition Pipeline Cleanup Utility

FILES

Add:
    utils/clean_ocr_acquisition_pipeline.py

Replace:
    utils/utils_main.py

NEW UTILITY MENU

=== ShopGraph Utilities ===

1. Export Clean Codebase
2. Clean OCR Acquisition Pipeline Data
0. Return to Utilities Menu

WHAT THE CLEANUP REMOVES

All contents inside:

    data/cropped/
    data/perspective_corrected/
    data/enlarged/
    data/ocr_variants/
    data/ocr_candidates/
    data/raw_ocr/

WHAT IT DOES NOT TOUCH

    data/current_pic/

The folder and all receipt images inside current_pic remain unchanged.

The generated output folders themselves are also preserved. Only their
contents are removed.

SESSION STATE

After cleanup, OCR Acquisition Pipeline session state is cleared so later
pipeline stages cannot accidentally reference deleted files.

RUN

    python3 main.py

Then:

    1. Utilities
    3. Utilities
    2. Clean OCR Acquisition Pipeline Data
