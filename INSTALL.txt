SIMPLIFIED WORKFLOW

You do not have to manually run every earlier step.

If you choose Perspective Correction first:
    choose receipt
    -> crop automatically
    -> perspective correction

If you choose Image Preprocessing first:
    choose receipt
    -> crop automatically
    -> perspective correction automatically
    -> preprocessing

If you choose Run OCR first:
    choose receipt
    -> crop automatically
    -> perspective correction automatically
    -> preprocessing automatically
    -> OCR

    <receipt>_preprocessed.png

data/raw_ocr/

Every stage uses one deterministic output per original receipt.
Running a stage again overwrites its existing output.
