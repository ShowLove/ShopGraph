ShopGraph - Capability Menu Update

PURPOSE

This update reorganizes utils/utils_main.py into three top-level sections:

1. Capabilities
2. Capability Sub Tasks
3. Utilities

TOP-LEVEL UTILS MENU

=== ShopGraph Utilities ===

1. Capabilities
2. Capability Sub Tasks
3. Utilities
0. Return to Main


1. CAPABILITIES

Currently contains:

1. OCR Acquisition Pipeline

Selecting OCR Acquisition Pipeline runs the complete capability in order:

1. Reliable Receipt Detection / Crop
2. Perspective Correction
3. 2x Enlargement
4. Generate OCR Image Variants
5. Run OCR - PSM 4 / 6 / 11
6. Compare OCR Results / Build Raw OCR JSON

The existing smart workflow is preserved. The receipt is selected at the
first stage and the later stages reuse the same session state and generated
artifacts.


2. CAPABILITY SUB TASKS

First choose a capability:

1. OCR Acquisition Pipeline

Then the existing individual stage menu appears:

1. Reliable Receipt Detection / Crop
2. Perspective Correction
3. 2x Enlargement
4. Generate OCR Image Variants
5. Run OCR - PSM 4 / 6 / 11
6. Compare OCR Results / Build Raw OCR JSON
0. Return to Capability Sub Tasks

Each stage can still be executed individually exactly as before.


3. UTILITIES

Currently contains:

1. Export Clean Codebase
0. Return to Utilities Menu


INSTALL

Replace only:

    utils/utils_main.py

No other files need to change.

Your existing top-level main.py already imports:

    from utils.utils_main import run_utils_menu

so it remains unchanged.
