ShopGraph - Corrected OCR Benchmark Update

ADD:
    utils/DataBaseBuilder/benchmark_writer.py

REPLACE:
    utils/DataBaseBuilder/data_base_builder_main.py
    utils/DataBaseBuilder/receipt_session.py

Behavior added:
- Review menu option 6: Accept Remaining Lines.
- Raw OCR JSON remains immutable.
- After a successful Excel commit, a corrected human-reviewed counterpart is written to data/benchmarks/ using the exact same filename as the raw OCR JSON.
- Reviewed OCR lines preserve original OCR text in original_ocr_text and expose corrected text plus human_review metadata.
- Skipped lines remain in the benchmark and are marked review_status=skipped.
- If a benchmark already exists, the user chooses whether to replace it or keep it.
- Cancelling before commit creates no benchmark.

Run normally:
    python3 main.py
