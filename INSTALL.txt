ShopGraph - Consensus OCR Comparison Update

PURPOSE

This update changes only Stage 6:

6. Compare OCR Results / Build Raw OCR JSON

Previously:
- all six OCR candidates were ranked
- one complete candidate won
- the other five candidates were discarded from the final transcription

Now:
- the best candidate is still used as the reading-order backbone
- every backbone line is compared against corresponding lines from all six candidates
- a clearer/more complete matching line can replace the backbone line
- lines missing from the backbone but independently supported by at least two candidates
  are preserved in supported_extra_lines
- every final line records which candidate produced it
- OCR characters are never silently corrected or rewritten

INSTALL

Replace:

    utils/compare_ocr.py

No other project files need to change.

RUN

From ShopGraph:

    1. Utilities
    6. Compare OCR Results / Build Raw OCR JSON

The existing smart pipeline remains intact. If earlier stages have not run in the
current session, they will run automatically.

OUTPUT

    data/raw_ocr/<receipt>_raw_ocr.json

Important fields:

    backbone_candidate
    consensus_summary
    raw_text
    text
    supported_extra_lines
    candidate_ranking
    provenance

The raw_text field contains the consensus backbone in receipt order.

The supported_extra_lines field is deliberately separate for this first test.
This avoids guessing where an omitted line belongs while still preserving
content seen independently by multiple OCR candidates.
