ShopGraph - Purchase History Data Base Builder

This update implements the first full Data Base Builder receipt-ingestion workflow.

ADD these files:
    utils/DataBaseBuilder/purchase_record.py
    utils/DataBaseBuilder/receipt_loader.py
    utils/DataBaseBuilder/receipt_session.py
    utils/DataBaseBuilder/parsers/__init__.py
    utils/DataBaseBuilder/parsers/base_parser.py
    utils/DataBaseBuilder/parsers/publix_parser.py
    utils/DataBaseBuilder/parsers/trader_joes_parser.py
    utils/DataBaseBuilder/parsers/aldi_parser.py
    utils/DataBaseBuilder/parsers/other_parser.py
    utils/DataBaseBuilder/excel/__init__.py
    utils/DataBaseBuilder/excel/purchase_history.py

REPLACE these files:
    utils/DataBaseBuilder/__init__.py
    utils/DataBaseBuilder/data_base_builder_main.py
    data/requirements.txt

No change is required to utils/utils_main.py because the current codebase already routes
Utilities option 4 to run_data_base_builder_menu().

Install/update dependencies from the project root using your normal environment, for example:
    pip install -r data/requirements.txt

Run:
    python3 main.py

Then choose:
    1. Utilities
    4. Data Base Builder
    1. Add Receipt to Purchase History

Raw OCR input is read from:
    data/raw_ocr/*_raw_ocr.json

The persistent workbook is created/updated at:
    data/database/shopgraph_purchase_history.xlsx

Workbook sheets:
    Purchase History
    Imported Receipts (hidden duplicate-import audit sheet)

The raw OCR JSON is never modified. Accepted lines are held in memory and the workbook is
written only when the receipt is finished. Cancelling a receipt leaves the workbook unchanged.
