ShopGraph - Portable Capability Package Update

GOAL

Move all Python code required for the OCR Acquisition Pipeline into:

    capabilities/OCRAcquisitionPipeline/

The user-facing menus and workflow remain the same.

NEW PROJECT STRUCTURE

shopping_analysis/

WHY THIS STRUCTURE

- capabilities/OCRAcquisitionPipeline contains the complete Python
  implementation of the capability.
- utils now contains only application-level utilities and menus.
- main_OCRAcquisitionPipeline.py exposes the top-level reusable function:

      run_ocr_acquisition_pipeline()

- Another Python project can import the capability entrypoint as:

      from capabilities.OCRAcquisitionPipeline import (
          run_ocr_acquisition_pipeline,
      )

IMPORTANT

The capability still expects the host project to provide the same data
layout beneath PROJECT_ROOT:

    data/current_pic/
    data/cropped/
    data/perspective_corrected/
    data/enlarged/
    data/ocr_variants/
    data/ocr_candidates/
    data/raw_ocr/

The capability-local constants.py determines PROJECT_ROOT from the folder
location, so when this capability folder is copied into another project at:

    <project>/capabilities/OCRAcquisitionPipeline/

it resolves the new project's root automatically.
